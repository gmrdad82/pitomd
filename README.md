# pitomd

Source for **[pitomd.com](https://pitomd.com)** — the landing page for
[Pito](https://github.com/gmrdad82/pito), the best YouTube tool. Built with
Astro, deployed to Cloudflare Pages.

## Local

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # → dist/
```
