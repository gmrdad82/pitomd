The worst part of an incident isn't the outage — it's reconstructing the
timeline afterward from chat scroll and adrenaline memory.

## File the incident as it happens

One card the moment it starts. Every significant move is a comment in its
thread — dated, attributed. Your monitoring agent can file findings over
MCP under its own name while you type with the other hand.

## References beat screenshots of configs

The card points at the runbook lines you followed and the config sections
you changed — `runbook.md#L44-61`, readable in place. Attach captures
where pixels matter; they're stored content-addressed and survive.

![A case file with state, references, and voices](/said-and-done/shots/casefile-light.png)

_The postmortem, pre-written: born, moved, cited, and signed._

## The postmortem is a read, not a dig

Open the case file: the whole life on one sheet — when it started, every
lane it crossed, every voice. Write the narrative from the record instead
of excavating one.
